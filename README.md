# 電帳DIY(デモ版)

レシート・請求書・払込用紙を「撮る・貼るだけ」で、日付・取引先・金額を自動で読み取り、
帳簿に残せる形式にファイル名を整えるツールです。

このリポジトリは**体験版(v1.0)**です。処理はすべてブラウザ内で完結し、
証憑データが外部サーバーに送信されることはありません。

## デモを試す

以下のURLからそのまま試せます。

- ライブデモ: `(GitHub Pages公開後にURLを追記)`

## できること(体験版)

- 画像(レシート写真・スクリーンショット)やPDFのドラッグ&ドロップ読み込み
- PDFにテキスト情報があれば、それを直接抽出(高精度)
- テキスト情報がない画像は、ブラウザ内蔵のOCRエンジンで文字認識
- 日付・取引先・金額を自動抽出(手動修正も可能)
- 固定フォーマットでのファイル名自動生成(`日付_取引先_金額.拡張子`)
- ローカルフォルダへの保存(Chrome/Edge推奨)、またはダウンロード

## 体験版の制限

- 1セッションにつき10件まで
- ファイル名の命名ルールは固定フォーマットのみ
- 払込用紙(電気・ガス・税金等)は検出のみで、内容の自動判定は非対応
- 勘定科目の自動サジェスト、インボイス番号チェック、Google Drive連携は非対応

これらは正式版(¥8,000・買い切り、アップデートは都度980円)で提供予定です。

## フォルダ構成

```
.
├── index.html         メイン画面
└── lib/
    ├── pdf.min.js       PDF解析ライブラリ(自前配信)
    └── pdf.worker.min.js
```

`index.html` は `lib/` フォルダ内のファイルを相対パスで参照しています。
公開・配布の際は、この2つのファイルを含む `lib/` フォルダごと一緒に配置してください。

## 使い方

1. `index.html` を開く(ローカルでのダブルクリック、またはGitHub Pages等で公開)
2. 証憑(画像・PDF)をドラッグ&ドロップ、またはクリックして選択
3. 自動抽出された日付・取引先・金額を確認し、必要なら修正
4. 「この内容で保存する」でファイル名を整えて保存

## 技術構成

- PDF解析:[pdf.js](https://mozilla.github.io/pdf.js/)(自前配信)
- 画像OCR:[Tesseract.js](https://tesseract.projectnaptha.com/)(CDN経由、インターネット接続が必要)
- サーバー・バックエンドなし、データはすべてブラウザ内で処理

## 注意事項

## 電子帳簿保存法の検索要件について

国税庁の解説によれば、電子取引データの検索要件は以下の3点です。

1. 取引年月日・取引金額・取引先で検索できること
2. 日付または金額の範囲を指定して検索できること
3. 2つ以上の検索項目を組み合わせて検索できること

ただし、税務職員からのダウンロードの求めに応じられる場合は上記2・3は不要になり、
**基準期間の売上高が5,000万円以下の事業者は、すべての検索要件が不要**になります。
多くの個人事業主はこの緩和の対象です。

検索要件を満たす方法は、専用システムの導入以外に、**事務処理規程を整備した上で、
ファイル名に取引年月日・取引先・金額を含める**という運用でも認められています。
本ツールはこの「ファイル名で満たす」方式を前提に設計しています。

出典:[国税庁「電子帳簿保存法が改正されました」(2021年12月)](https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/pdf/0021005-038.pdf)

## 制度改正について

2026年9月末でインボイス制度の2割特例が終了し、個人事業主向けに3割特例が新設される
予定です。免税事業者からの仕入税額控除も段階的に縮小されるため、日々の証憑管理・
記帳の重要性は今後さらに高まります。本ツールは制度改正に合わせて継続的に
アップデートしていく予定です。
