## 税務調査で「この取引の書類を見せてください」と言われたとき、すぐ出せますか?

メールやWebサイトで受け取った請求書・領収書・カード明細などの**電子データは、電子データのまま保存**しておく必要があります。そして調査のとき、税務職員から「**この取引の書類を見せてください(ダウンロードの求め)**」と言われたら、**探して出せる状態**にしておかなければなりません。

けれど実際のフォルダは、`scan_001.pdf`、`領収書(2).pdf`、`ダウンロード.pdf`……と、名前がバラバラになりがちです。

**電帳DIY** は、書類を読み取って、

- ファイル名を **「日付_取引先_金額円_書類種類」** にそろえ(元のファイルは変更せず、名前を直したコピーを出力します)
- **年月フォルダ**に仕分け
- **日付・金額・取引先で検索**できる「電帳ダッシュボード」と、提出用の**一覧CSV**を作る

ところまでを、ブラウザの中だけで行うツールです。

> **ご参考**:基準期間(前々年など)の売上高が5,000万円以下の事業者は、ダウンロードの求めに応じられる状態にしてあれば、「検索機能の確保」の要件そのものは不要とされています(国税庁・一問一答 問49・問51)。その場合でも、**求められたときに書類を探して出せる状態**であることは変わりません。電帳DIYは、そのための整理を、会計ソフトなしで、手元のフォルダのまま進められるようにするものです。

## 3ステップで体験(約2分)

1. **開く**:上のデモのURLを、パソコンの **Chrome または Edge** で開きます。
2. **書類を選ぶ**:画面上部の「**▶ サンプル書類で体験する**」を押します。ご自身の書類で試すときは、画面中ほどの「03 証憑を読み込む」から、書類を選びます(中身は変更しません)。体験版では3件まで読み取れます。
3. **確認する**:読み取り結果を書類の画像(拡大できます)と見比べて「この内容で登録」。最後に「📊 電帳ダッシュボード」で検索を体験できます。

## 毎月の「取得予定」をお知らせ

Amazon・楽天・カード・銀行などの明細を取る日を登録しておくと、ホームの「今月の取得予定」でお知らせします(取得日が近い・過ぎているものを先頭に表示)。明細のページを開くリンクも登録できます。

- **お知らせだけ**です。サイトへのログインや、PDFの自動取得は行いません(保存はご自身で行い、「証憑を読み込む」から取り込みます)。
- 予定を「カレンダー用のファイル(.ics)」に書き出して、Google カレンダーなどに取り込むと、電帳DIYを開いていないときも、取得日の朝9時に通知が届きます。
- 予定は、お使いのブラウザの中にだけ保存されます。外部には送信しません。
- 将来、拡張機能として、ご本人の承認のうえで取得を助ける機能を検討しています。

## 書類は、あなたのパソコンの外に出ません(すべてローカルで完結)

電帳DIYは、「インターネット上のサービス」ではなく、**あなたのパソコンの中で動くアプリ**です。ブラウザ(Chrome / Edge)を、作業用の机として使っているだけです。

- 書類の**読み取りも、名前の整理も、台帳づくりも、検索も、すべてあなたのパソコンの中**で行います。
- 書類を**どこかのサーバーにアップロードすることはありません**。アカウント登録もログインも不要です。作者(A2E Works)にも、書類やその内容は届きません。
- たとえるなら、書類を**郵送せずに、自分の机の上で整理する**ようなものです。

### 通信が発生するのは、次の2つだけです

どちらも、道具や情報を**受け取る(ダウンロードする)**通信です。あなたの書類は含まれません。

| 場面 | 何を受け取るか |
|---|---|
| ページを開いたとき・初めて読み取るとき | 文字を読み取るための部品(OCR・PDFの部品) |
| 「最新化」ボタンを押したとき | 制度アップデートの情報(押したときだけ) |

部品がいったん保存されたあとは、**ネットを切っても動きます**。「本当に外に出していないか」は、一度、ネットを切って整理してみることで、ご自身で確かめられます。

### 書類・記録が置かれる場所

- 元のファイルは**変更・削除しません**。デモ版は、ファイルの書き出し自体を行いません(正式版は、あなたが選んだフォルダに、新しい名前のコピーを書き出します)。
- 台帳などの記録は、**お使いのブラウザの中**に保存されます(暗号化はされません)。共用のパソコンでは使わないでください。ブラウザのデータを消すと、記録も消えます。
- 銀行・カード会社への接続や、ID・パスワードの入力は一切ありません(ご自身でダウンロードした書類を読み込むだけです)。

## 動作環境・注意

- 推奨:パソコンの Chrome / Edge。スマホではファイル選択のみです。
- 対象は、**電子データで受け取った書類**です。紙の書類を撮影した画像は、スキャナ保存という別の制度の対象で、電帳DIYは、その要件を満たすものではありません(撮影した書類の名前を整える補助としてはお使いいただけます)。
- 台帳などのデータはお使いのブラウザ内に保存されます(暗号化はされません)。共用のパソコンでは使わないでください。
- 本ツールは、書類の整理・検索・一覧出力を助けるものです。税務調査への対応を保証するものではありません。制度の詳細は国税庁の資料と、税務署・税理士にご確認ください。
